# Annual Reports PDF Files

This directory contains the annual reports and annual accounts for NIT Goa.

## Directory Structure:
- `english/` - Contains English version annual reports
- `hindi/` - Contains Hindi version annual reports

## Usage:
These PDF files are served directly from the public directory and opened in new tabs when clicked on the Annual Reports page.

## File Naming Convention:
- Use lowercase with underscores for consistency
- Include the academic year in the filename
- Prefix Hindi versions with "hindi_"
