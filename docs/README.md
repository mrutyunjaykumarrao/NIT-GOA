## 🚀 Quick Start

### For Developers
1. **Setup**: `npm run install-all`
2. **Development**: `npm run dev`
3. **Testing**: `npm test`

### For Content Managers
- Login as admin through the website
- Access the dashboard to manage content
- Upload images, PDFs, and notices
- Manage faculty profiles
